# Governance

How FDE for Good is run today, and how that's meant to evolve. This is intentionally lightweight — we're a small volunteer collective, not a bureaucracy. It grows only as much as it has to.

## Today: a volunteer collective

- **Maintainers** steward the project: review contributions, vet incoming requests against [who we help](who-we-help.md), and help match volunteers to engagements.
- **Volunteers (FDEs)** do the engagement work. Anyone can become one — see [for-volunteers.md](for-volunteers.md).
- **Partners** are the organizations we help.

No legal entity exists yet. No money changes hands. Decisions are made openly in issues and PRs, with maintainers as tie-breakers.

## How decisions get made

- **Day-to-day** (taking on an engagement, scoping, technical choices): the volunteers and maintainers involved decide, in the open.
- **Project-wide** (eligibility, principles, direction): proposed as an issue, discussed, decided by maintainer consensus. Default to transparency — if a decision would surprise a contributor, it should have been an issue.
- **Disputes / conduct:** handled per the [Code of Conduct](../CODE_OF_CONDUCT.md).

## Roles we'll need as we grow

These don't all exist yet — listing them so we know what we're building toward:

| Role | Responsibility |
|------|----------------|
| Maintainers | Project stewardship, request vetting, volunteer matching |
| Partnerships | First point of contact for orgs; runs intake & scoping |
| Volunteer coordination | Onboarding, matching, keeping volunteers supported |
| Treasurer (later) | Once we can take donations — finances & transparency |
| Board / trustees (later) | Required when we incorporate — see [becoming-a-nonprofit.md](becoming-a-nonprofit.md) |

## Principles for governance

- **Transparent by default.** Decisions, finances (eventually), and reasoning are public.
- **Light until it can't be.** Add process only when the lack of it causes real problems.
- **Volunteers come first.** The project only works if helping here feels good and sustainable.
- **No mission drift.** Every change is checked against: are we still helping people locked out of software?

## Changing this document

Open a PR. Significant governance changes should sit as an issue for discussion first.
