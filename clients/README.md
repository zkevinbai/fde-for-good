# Clients

Every engagement lives here, organized by the organization we're helping.

## Structure

```
clients/
└── <client-name>/              # one folder per organization (kebab-case)
    ├── README.md               # who they are, contact, status
    └── projects/
        └── <project-name>/     # one folder per project (kebab-case)
            ├── README.md       # the problem, plan, status, handover notes
            └── ...             # the actual code, self-contained
```

## Starting a new client

1. Copy [`_template-client/`](_template-client/) to `clients/<client-name>/`.
2. Fill in the client `README.md`.
3. Copy the project template for each new project under `projects/`.

## Naming

Use lowercase kebab-case: `riverside-food-bank`, `youth-coding-trust`. Keep it recognizable but you don't have to use the org's exact legal name.
